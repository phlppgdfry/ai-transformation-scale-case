# ISO/IEC 27001 and ISO/IEC 42001

Ardena is certified against ISO/IEC 27001:2022. The AI programme should use that management system, not build a parallel one.

## Using the existing ISMS for AI

| ISO/IEC 27001 (Annex A theme) | What changes for AI |
|---|---|
| Organisational: supplier relationships | AI vendors and SaaS with embedded AI go through supplier assessment: data processing location, training on customer data, sub-processors, incident duties |
| Organisational: information classification | Data classes map to the approved model catalogue: which class may go to which model |
| Organisational: inventory of assets | The AI register is part of the asset inventory |
| Technological: logging and monitoring | Gateway traces and cost logs, redacted |
| Technological: secure development | Prompt-injection screening, evaluation gate and least-privilege tools in the build standard |
| People: awareness and training | AI literacy module added to annual security awareness |

## ISO/IEC 42001: certify or align?

ISO/IEC 42001:2023 specifies an AI management system with the same high-level structure as 27001 (context, leadership, planning, support, operation, performance evaluation, improvement), plus AI-specific controls such as AI impact assessment and AI system lifecycle.

**Recommendation: align now, decide on certification in 12 months.** The AI council, policy, register, intake and impact assessments map onto 42001's requirements and can be run inside the existing ISMS. Certification makes sense if customers, partners or regulators start asking for it, or if Ardena builds AI that others rely on.
