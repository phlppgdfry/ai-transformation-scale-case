# From 37 AI pilots to a portfolio in production

**An AI transformation case at enterprise scale (fictional).** A Belgian grocery retailer with 11,000 people has AI "everywhere and nowhere". The case covers the full engagement: organisational AI readiness, triage of every existing initiative, governance and an AI orchestration layer, a workshop series that produces a ranked growth map, a differentiation strategy, an 18-month roadmap, and a pilot that proves value against a comparison group and then meets the gates to production.

> *"We have AI everywhere and nowhere. I cannot name one AI initiative that changed our P&L. I want to know which bets to make, how to organise ourselves, and one thing that proves it."* — the client's CEO

[![CI](https://github.com/phlppgdfry/ai-transformation-scale-case/actions/workflows/ci.yml/badge.svg)](../../actions/workflows/ci.yml)

## The answer in one paragraph

**Govern first, bet on fresh, prove it properly.** Maturity is <!--n:rd.overall-->2.3<!--/n--> of 5 and governance is the largest gap, so a fast-lane intake, a register and an orchestration layer come in the first three months. Of <!--n:inv.total-->37<!--/n--> initiatives, <!--n:inv.stop-->8<!--/n--> stop, <!--n:inv.merge-->4<!--/n--> merge and <!--n:inv.pause-->3<!--/n--> pause for an AI Act assessment. Ardena's AI advantage is in **fresh**: a third of sales and the reason customers come, and nobody else is investing there. The fresh markdown advisor ranks first under <!--n:pf.UC-01.top5-->93%<!--/n--> of random weightings, and in 12 matched store pairs it cut fresh waste by <!--n:pilot.effect-->0.88 pp<!--/n--> (<!--n:pilot.relative-->18%<!--/n-->). Getting it into 240 stores is gated on <!--n:prod.blockers-->5<!--/n--> open production gates, and none of them is about the model.

## Run it

Python 3.11 or newer, no dependencies.

```bash
python -m unittest discover -s tests -t .   # toolkit tests
python scripts/build.py                     # recompute every number and table in the docs and site
python -c "from aitx import pilot; print(pilot.evaluate()['decision'])"
```

Change a weight in `data/weights.json` or an assumption in `data/finance.json`, run the build, and every document and chart follows.
